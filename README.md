# Directors-cut-1.0
Essential film making techniques, from shots to editing, all in one place.

### Problem Description

Filmmaking uses a lot of special terms for shots, movements, editing, lighting, and more. The problem is that this information is often scattered across many different articles and glossaries, making it hard for learners to find and understand everything in one place.

This project solves that by bringing all those terms together into one clear and organized dataset. With a simple format (type, term, definition, and extra), it’s easy to search, study, and explore filmmaking concepts without the confusion of hunting through multiple sources.
